# Employee Tracking SaaS - Database Design

## Overview

The platform uses **PostgreSQL** with **PostGIS** for efficient storage
and querying of GPS coordinates. It follows a **multi-tenant**
architecture where every record belongs to a company (tenant).

------------------------------------------------------------------------

# Database Schema

## companies

  Column              Type        Description
  ------------------- ----------- -----------------
  id                  UUID        Primary Key
  name                VARCHAR     Company name
  subscription_plan   VARCHAR     Current plan
  status              BOOLEAN     Active/Inactive
  created_at          TIMESTAMP   Creation time

------------------------------------------------------------------------

## users

  Column          Type
  --------------- -----------
  id              UUID
  company_id      UUID (FK)
  role            ENUM
  name            VARCHAR
  email           VARCHAR
  phone           VARCHAR
  password_hash   TEXT
  status          BOOLEAN
  created_at      TIMESTAMP

Roles: - Super Admin - Company Admin - Manager - Employee

------------------------------------------------------------------------

## employee_profiles

Stores employee-specific information.

Fields: - id - user_id - employee_code - department - designation -
joining_date

------------------------------------------------------------------------

## tracking_settings

Company-specific tracking configuration.

Fields: - company_id - tracking_mode - tracking_interval -
stop_duration - working_start - working_end - minimum_accuracy

Tracking Modes: - SHIFT - ALWAYS_ON - SCHEDULED

------------------------------------------------------------------------

## shifts

Employee working sessions.

Fields: - id - employee_id - start_time - end_time - status

------------------------------------------------------------------------

## location_logs

Stores every GPS update.

Fields: - id - company_id - employee_id - latitude - longitude -
accuracy - altitude - speed - heading - battery_level - activity_type -
recorded_at

Recommendations: - Enable PostGIS geometry/geography. - Partition by
month. - Index employee_id and recorded_at.

------------------------------------------------------------------------

## stops

Generated by stop detection.

Fields: - id - employee_id - latitude - longitude - arrival_time -
departure_time - duration_minutes

------------------------------------------------------------------------

## geofences

Fields: - id - company_id - name - latitude - longitude - radius

------------------------------------------------------------------------

## attendance

Fields: - id - employee_id - check_in - check_out - working_minutes

------------------------------------------------------------------------

## notifications

Fields: - id - employee_id - type - title - message - is_read -
created_at

------------------------------------------------------------------------

## subscriptions

Fields: - id - company_id - plan_name - employee_limit - expires_at -
status

------------------------------------------------------------------------

## audit_logs

Tracks sensitive actions.

Fields: - id - company_id - user_id - action - ip_address - created_at

------------------------------------------------------------------------

# Relationships

``` text
Company
 ├── Users
 │     ├── Employee Profile
 │     ├── Shifts
 │     ├── Location Logs
 │     ├── Stops
 │     ├── Attendance
 │     └── Notifications
 ├── Tracking Settings
 ├── Geofences
 └── Subscription
```

------------------------------------------------------------------------

# Performance Strategy

-   PostgreSQL + PostGIS
-   Monthly table partitioning for location_logs
-   Composite indexes on (company_id, employee_id, recorded_at)
-   Redis cache for live locations
-   Archive old GPS data while keeping summary reports

------------------------------------------------------------------------

# Data Retention

-   Raw GPS logs: configurable (e.g. 6--12 months)
-   Reports: long-term
-   Audit logs: long-term
-   Soft delete for users where required
